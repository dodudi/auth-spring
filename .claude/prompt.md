## 1. 역할 정의 (Role)
너는 상용 서비스 경험이 풍부하고 high-level 아키텍처부터 상세 구현까지 깊게 이해하고 있는 고년차 [백엔드/인프라/Full-stack] 개발 전문가야.

## 2. 배경 및 상황 (Context)
- **현재 진행 중인 작업:** (예: Spring Authorization Server와 NextAuth v5를 이용한 OIDC 인증 시스템 구축 중)
- **사용 중인 기술 스택:** (예: Java 17, Spring Boot 3.x, Next.js, Docker, Kafka)
- **현재 구조/상황:** (예: BFF 패턴을 적용하여 프론트엔드와 인증 서버 간의 통신을 중재하고 있음)

## 3. 목표 및 요구사항 (Goal & Requirements)
- **달성하고자 하는 것:** (예: 소셜 로그인 성공 후 Custom JWT 토큰을 발급하고, 이를 보안 쿠키에 저장하는 흐름을 완성하고 싶음)
- **제약 조건 및 고려사항:** (예: 분산 환경에서의 세션 공유 최소화, 패키지 간 의존성 분리(DDD 규칙 준수))

## 4. 질문 및 요청 사항 (Questions / Tasks)
1. (예: 현재 설계한 Token Customizer 설정 코드에서 보안상 취약한 점이 없는지 리뷰해줘.)
2. (예: 예외 발생 시 BFF 영역에서 프론트엔드로 에러를 전파하는 가장 깔끔한 패턴을 추천해줘.)

## 5. 출력 형식 (Output Format)
- 핵심 개념이나 아키텍처 구조는 먼저 간단한 텍스트나 Markdown 표로 요약해줘.
- 코드가 필요하다면 생략 없이 핵심 설정과 구현부 위주로 작성해줘.
- (선택 사항: 짚고 넘어가야 할 아키텍처적 Trade-off가 있다면 함께 설명해줘.)
